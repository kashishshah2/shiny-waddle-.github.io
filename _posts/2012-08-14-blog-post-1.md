So far, this course has helped me develop a much better understanding of how websites can be created and managed using GitHub. I have learnt how to clone a repository, edit files locally, commit changes, push them to GitHub, and pull remote changes back to my computer.

I have particularly enjoyed seeing changes made in the code appear on a live website, as this has made the process feel practical and rewarding. Some parts, such as understanding the difference between local and remote repositories and fixing Git errors, have been challenging, but working through these problems has helped me become more confident using GitHub.

I am looking forward to learning more about website customisation and continuing to develop my academic website into something that reflects my interests, experiences and future work.
